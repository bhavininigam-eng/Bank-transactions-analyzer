# Bank Transactions Analyzer

## Project Overview
Bank Transactions Analyzer is a Python-based
mini project that analyzes bank transactions
using Pandas and NumPy.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Features
- Transaction dataset generation
- Total income calculation
- Total expense calculation
- Balance calculation
- Highest and lowest transaction detection
- Category-wise expense analysis
- Monthly financial summary
- Data visualization
- Transaction search

## Project Structure

Bank-Transactions-Analyzer/
│
├── Bank_Transactions_Analyzer.ipynb
├── Bank_Transactions.csv
└── README.md

## How to Run
1. Download the notebook.
2. Open Google Colab.
3. Upload the notebook.
4. Run all cells.

## Conclusion
This project demonstrates how Python,
Pandas and NumPy can be used to analyze
financial transaction data and generate
useful insights.
